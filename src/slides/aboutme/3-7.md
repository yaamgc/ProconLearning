# グループ化１
ページ内のコンテンツをグループ化し、CSSを適用する際には**divタグ**を用います。
divタグのclass属性で指定した「特定のクラス」をCSSで編集することで、要素の見た目を変えることができます。

```html
<div class="指定するクラス名">
    <h1>見出し</h1>
    <p>本文</p>
<div>
```

今回は、今まで書いた自己紹介の内容をグループ化して、カードのような見た目にしたいので、全体をdivで囲い、cardというクラスを付けます。
```html 
<div class="card"> <!-- ←New -->
<h1>山田太郎</h1>
<img src="画像のリンク先">
<p>1-1</p>
<p>趣味：プログラミング</p>
<p>一言：よろしくお願いします。</p>
</div> <!-- ←New -->
```

これで自己紹介サイトの基盤は完成しました。
