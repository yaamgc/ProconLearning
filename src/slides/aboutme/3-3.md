# タグと要素について

## タグとは...
HTMLという言語を構成する部品！
```html
<h1>中身</h1>
<!-- h1は見出しを表すタグ -->
```
のような開始タグ（<タグ名>）と終了タグ（</タグ名>）のセットで記述するものや、
```html
<br>
<!-- brは改行を表すタグ -->
```
のような一つのタグだけで記述するものがあります。

また、「開始タグ、中身、終了タグ」全体を要素といいます。

## 属性とは...
タグに追加の情報や設定を与えるためのもの！
```html
<img src="リンク先">
<!-- リンク先の画像を表示させるタグ -->
```
のように属性名="値"のような形で記述します。
属性は一つのタグに複数使用可能です。
