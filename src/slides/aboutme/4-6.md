# card内の要素を中央寄せ
text-alignを使うことによって、**中身**の要素を「中央寄せ、左寄せ、右寄せ」にすることができます。

```css
text-align:center;
/* 中央寄せ */
text-align:left;
/* 左寄せ */
text-align:right;
/* 右寄せ */
```

今回はcenterを指定して、カードの中身を中央寄せにします。
```css
.card{
    background-color:white;
    margin: 100px auto;
    padding: 50px;
    width: 400px;
    text-align: center;
    /* ↑New! */
}
```
