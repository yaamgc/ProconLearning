# 画像を挿入する1＆属性
画像を表示させるためのタグにはimgを使います。

src属性で画像のリンク先を指定します。
```html
<img src="画像のリンク先">
```
自己紹介用画像を用意し、「自己紹介サイト」フォルダに移動させた後、名前の下に以下のように画像を配置してみましょう。

画像のリンク先は、
左のファイル一覧から、画像ファイルを右クリック、「相対パスをコピー」
で取得することができます。
```html
<h1>山田太郎</h1>
<img src="画像のリンク先">
<!-- ↑New! -->
<p>1-1</p>
<p>趣味：プログラミング</p>
<p>一言：よろしくお願いします。</p>
```
![3-5-0](/image/html2.png )
これで画像が表示されるようになったはずです。
