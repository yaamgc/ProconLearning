# 色をつけよう
CSSの色を指定するプロパティには以下のようなものがあります。
```css
color: black;
/* 文字色を指定するプロパティ */
border-color: black;
/* 枠線の色を指定するプロパティ */
background-color: black;
/* 背景色を指定するプロパティ */
```

bodyとcardの背景色を以下の例のように設定してみましょう。（色はお好みで大丈夫です）
```css
body{
    background-color: rgb(0, 140, 255);
}
.card{
    background-color:white;
}
```
