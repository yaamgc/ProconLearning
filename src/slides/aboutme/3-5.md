# 文字を入れてみる
見出しのタグは、文字が大きい順にh1~h6があります。
```html
<h1>見出し1</h1>
<h2>見出し2</h2>
<h3>見出し3</h3>
<h4>見出し4</h4>
<h5>見出し5</h5>
<h6>見出し6</h6>
```
また、本文のタグにはpを使います。
```html
<p>本文</p>
```

これを踏まえて、body要素内に、下の例のような自己紹介文を書いてみましょう。
```html
<h1>山田太郎</h1>
<p>1-1</p>
<p>趣味：プログラミング</p>
<p>一言：よろしくお願いします。</p>
```
