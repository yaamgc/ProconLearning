# コミット
## コミットとは？
ローカルリポジトリの変更をローカルリポジトリに記録する操作をコミットといいます。

## README.mdをコミットしよう
README.mdというGithubにおいて「最初に見るべき説明書」として使われるファイルを作成し、コミットをしてみましょう。

Open in Visual Studio Codeを押し（VSCode上でgit-practiceファイルを開く）、README.mdを作成して、内容を以下のようにして保存してください。

```md
# Hello,world
Initial commit
```

保存後、GitHub Desktopを開き、
- 変更内容の要約
- 変更内容の説明

を入力後、Commit 1 file to mainを押すことでコミット完了です。
