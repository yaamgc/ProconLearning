# ブランチ
## ブランチとは？
ブランチ（枝）とは、完成版を管理する**メインブランチ**から分かれて作業を行うための**作業領域**です。

通常、**新しい機能の実装**や**不具合修正**などの作業は専用のブランチで進め、問題がないことを確認してからメインブランチに取り込みます。

## ブランチを作ってみよう
「Current branch→New branch」をクリックし、Nameをfeature/add-profileとし、「Create branch」を押しましょう。
![alt text](</image/スクリーンショット 2026-10-28 140728.png>)

そして、「Publish branch」を押すことで、リモートリポジトリにブランチが作成されます。
![alt text](</image/スクリーンショット 2026-10-28 140817.png>)
## ブランチで作業してみよう
プロフィール文章を作るだけの簡単な作業を行ってみます。

「profile.md」というマークダウンファイルを作成し、適当にプロフィールを記述後、保存してください。
```md
# 私の名前は山田太郎です！
趣味はプログラミング
好きな科目は数学です
```
「Current branch」が「feature/add-profile」になってるのを確認してから、コミット、プッシュをしましょう。

これで完了です。
