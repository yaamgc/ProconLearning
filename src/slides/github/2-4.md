# クローン
## クローンとは
リモートリポジトリを、ローカルにコピーして、PC内で作業できるようにする作業をクローンといいます。

## リモートリポジトリをクローンしよう

今回は、先ほどgithub上で作成したリモートリポジトリをクローンしていきます。
![alt text](</image/スクリーンショット 2026-10-26 231232.png>)
リポジトリ新規作成後、リポジトリのページに出てくる「Set up in GitHub Desktop」をクリックして、GitHub Desktop上でCloneを押しましょう。
![alt text](</image/スクリーンショット 2026-10-26 232110.png>)
これで作成したリポジトリがクローンされました。
