# マージ＆プルリク
他のブランチで行った作業をメインブランチに統合する作業を**マージ**といいます。

また、マージする前に、変更を他のチームメンバーにチェックしてもらうよう依頼する仕組みを**プルリク**（プルリクエスト）といいます。

## プルリクをしてみよう
![alt text](</image/スクリーンショット 2026-10-28 145714.png>)
ブランチでの作業完了後、GitHub Desktopで「Preview Pull Request」を押し、「Create pull request」を押すと、githubのページに遷移します。

githubのサイトへ遷移後、Writeに変更内容を記述し、Create pull requestを押すことで、プルリク完了です。

プルリクは、githubのリポジトリの「Pull requests」のページで見ることができます。
## マージをしてみよう
リポジトリの「Pull requests」のページで、プルリクに対して、「Merge pull request」を押すことで、そのプルリクをマージすることができます。
