# リポジトリを作成しよう

## リポジトリとは？
ソースコードやファイル、変更履歴をまとめて保存する場所を**リポジトリ**といいます。ローカル上（PC内）のリポジトリを**ローカルリポジトリ**、クラウド上（Github）のリポジトリを**リモートリポジトリ**といいます。

## リモートリポジトリを新規作成しよう
![alt text](</image/スクリーンショット 2026-10-26 225506.png>)
まず、githubのサイトの右上のプラスボタン→New repositoryを押して、「Create a new repository」と書かれたサイトに飛びます。

![alt text](</image/スクリーンショット 2026-10-26 225640.png>)
次に、
- Repository nameにリポジトリ名（今回はgit-practice）
- Descriptionにリポジトリの説明（任意）


を入力し、
Choose visibilityで公開設定を指定しましょう。


今回は非公開で大丈夫です。

- 公開の場合：誰でも見られる
- 非公開の場合：自分と招待した人だけ見られる

これで、Create repositoryをクリックすると、リモートリポジトリの作成は完了です✅
